# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

Rendy's personal site/blog (https://rendybjunior.com, custom domain set in `docs/CNAME`). It is a **MkDocs + Material for MkDocs** site — there is no application code, just Markdown content, theme overrides, and one Python build-time hook.

## Common commands

```bash
pip install -r requirements.txt   # install MkDocs, Material, RSS, glightbox, social/imaging extras
mkdocs serve                      # local dev server with live reload
mkdocs build                      # build static site into ./site
mkdocs gh-deploy --force          # what CI runs to publish to gh-pages
```

The Material `social` plugin requires Cairo/Pango system libraries (installed via `mkdocs-material[imaging]`); if `mkdocs serve` fails on image generation locally, that is the usual cause.

## Deployment

`.github/workflows/ci.yml` runs `mkdocs gh-deploy --force` on every push to `main` or `master`. There is no separate build/test step — pushing to main publishes. Treat `main` as production.

## Content structure

- `docs/index.md` — landing page.
- `docs/blog/posts/*.md` — blog posts. Filenames are `YYYY-MM-DD-slug.md`; each post has frontmatter with `title`, `date.created`, `authors` (must match an id in `docs/blog/.authors.yml`), `categories`, and `tags`. A `<!-- more -->` marker splits the excerpt from the body.
- `docs/blog/.authors.yml` — author registry referenced by post frontmatter.
- `includes/abbreviations.md` — auto-appended to every page via `pymdownx.snippets` for global abbreviation definitions.

## Customizations worth knowing

- **`hooks/socialmedia.py`** is registered as a MkDocs hook in `mkdocs.yml`. Its `on_page_markdown` hook appends "Share on X / Facebook" buttons to pages whose URL matches the regex `blog/[1-9].*` — i.e. only individual posts (year-prefixed paths), not blog index/tag pages. Changes to post URL structure can silently disable these buttons.
- **`overrides/partials/comments.html`** is a Material theme partial override that injects a giscus comments widget, but **only when a page sets `comments: true` in its frontmatter**. The giscus repo/category IDs are hardcoded to `rendybjunior/rendybjunior.github.io`.
- **RSS** is generated by `mkdocs-rss-plugin`, scoped to `blog/posts/.*` and using `date.created` / `date.updated` from post frontmatter.
- A wide set of `pymdownx.*` extensions is enabled (admonitions, details, tabbed, critic, keys, mark, mermaid via `superfences`, emoji via twemoji, line-numbered highlighting). When authoring posts, prefer these over raw HTML.

## When adding a blog post

1. Create `docs/blog/posts/YYYY-MM-DD-slug.md` with the same frontmatter shape as existing posts.
2. Use an author id that already exists in `docs/blog/.authors.yml` (or add a new one there first).
3. Include `<!-- more -->` after the excerpt paragraph.
4. To enable comments on the post, add `comments: true` to its frontmatter.
